## گُماشتَن (Gboard)

<div dir="rtl">

1. پرونده واژه‌نامه را دریافت کنید:
   - بارگیری  [واپَسین نَسْکه](https://github.com/lnxpy/vajeban/releases/latest).

2. پرونده را به گوشی اندروید خود فِرِستِش کنید.

3. در Gboard به این مسیر بروید:

   `Gboard Settings → Dictionary → Personal dictionary → Persian (فارسی) → ⋮ → Import`

   پرونده بارگیری شده را گُزینِش کنید.

4. انجام شد. اکنون با نوشتن یک واژه بُرون مَرزی (مثلاً «سلام»)، برابر فارسی آن (مثلاً «درود») پیشنهاد می‌شود.

</div>
